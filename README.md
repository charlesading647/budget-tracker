# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application built using HTML and CSS. It is designed to help users record and view their expenses in one place.

## Features

### 1. Add Expense Form

The form allows users to enter an expense name and amount, then select a category such as:

* Food
* Transport
* Rent
* Entertainment
* Other

### 2. Expense Table

The expense section displays sample expenses in a structured HTML table. The table contains:

* Name
* Amount
* Category
* Date

### 3. Multimedia

The project includes a budget tracker image and an embedded YouTube video containing budgeting tips.

### 4. How to Use

A collapsible section explains how to use the expense tracker. It uses the HTML `details` and `summary` elements.

## Technologies Used

* HTML5
* CSS3

## Project Files

* `index.html` - Contains the structure and content of the Budget Tracker.
* `style.css` - Contains the styling, layout, table design, hover effects, and advanced CSS selectors.
* `script.js` - JavaScript file reserved for future functionality.
* `README.md` - Provides information about the project and its features.

## CSS Features

The project uses:

* Descendant selectors
* `:focus` pseudo-class
* `:nth-child(even)` pseudo-class
* `:hover` pseudo-class
* `cursor: pointer`

JavaScript functionality can be added in future weeks to allow users to add expenses dynamically and make the Budget Tracker interactive.
